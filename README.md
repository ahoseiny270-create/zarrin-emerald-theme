# زرین زمرد — دموی سوم 🟢✨

قالب فروشگاهی **طلا و جواهر برای وردپرس** — نسخه زمرد تیره (Emerald Noir)، کاملاً راست‌چین و فارسی، سازگار با ووکامرس، دارای قیمت لحظه‌ای طلا و سکه و «راه‌اندازی دمو با یک کلیک».

> این مخزن **دموی سوم** خانواده قالب‌های زرین است.

## 🎨 هویت بصری این دمو

| عنصر | مقدار |
|---|---|
| رنگ اصلی | زمرد تیره `#04140F` → `#0B2E25` |
| رنگ مکمل | طلای شامپاینی `#D9B96A` |
| پس‌زمینه روشن | مرمر عاجی `#FCFAF4` |
| موتیف امضا | قوس/طاق (Arch) در هیرو، تصاویر محصول و کارت‌های وبلاگ |
| حس و حال | لوکس، آرام، شب‌رنگ، گالری‌وار |

## 👨‍👩‍👦 خانواده دموهای زرین

| # | دمو | تم | مخزن |
|---|-----|----|------|

ساختار PHP هر سه دمو یکسان است و فقط فایل استایل، تصاویر نمونه و متن‌ها تفاوت دارند — یعنی می‌توانید ظاهر سایت را با عوض کردن پوسته تغییر دهید و هیچ قابلیتی از دست نرود.

## ✨ قابلیت‌ها

- **صفحه اصلی اختصاصی**: هیرو، تیکر قیمت، مزیت‌ها، محصولات ویژه، درباره ما، بنر تماس و وبلاگ
- **قیمت لحظه‌ای طلا و سکه**: دریافت خودکار از بازار (tgju.org)، کش سمت سرور، آخرین قیمت معتبر تا ۲۴ ساعت، نشانگر درصد تغییر سبز/قرمز
- **ووکامرس**: استایل اختصاصی فروشگاه، محصولات ویژه، شمارنده سبد خرید با آجاکس، واحد پول تومان
- **راه‌اندازی دمو با یک کلیک**: ساخت برگه‌ها، منوها، نوشته‌ها، محصولات، تصاویر و تنظیمات
- **فونت وزیرمتن متغیر** به‌صورت لوکال (بدون CDN)
- **پنل تنظیمات** کامل در «نمایش ← سفارشی‌سازی»
- دسترس‌پذیری: پرش به محتوا، `aria` مناسب، احترام به `prefers-reduced-motion`

## 🚀 نصب

1. فایل `zarrin-emerald-theme.zip` را از بخش Releases دانلود کنید (یا کل مخزن را در پوشه `wp-content/themes/` بگذارید).
2. در پیشخوان: **نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته** و انتخاب فایل زیپ.
3. پوسته را فعال کنید و دکمه **«راه‌اندازی دمو با یک کلیک»** را بزنید.

نیازمندی: وردپرس ۶ به بالا — PHP 7.4 به بالا — افزونه ووکامرس (برای بخش فروشگاه)

## 🔧 تغییرات این دمو نسبت به دموی اول

- پالت رنگ کامل جدید (زمرد/عاجی/شامپاینی) و بازطراحی هدر، فوتر، دکمه‌ها و کارت‌ها
- موتیف طاق در تصاویر و قوس‌های تزئینی گوشه‌ها
- شماره‌گذاری خودکار فارسی روی کارت‌های مزیت
- تصاویر نمونه اختصاصی (مخمل زمرد، مرمر عاجی، کارگاه طلاسازی)
- **رفع باگ**: آیکون‌های اینستاگرام و واتساپ در هدر و فوتر رندر نمی‌شدند (عدم تطابق کلیدهای `insta`/`whats` با `instagram`/`whatsapp`)
